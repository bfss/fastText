# fastText

This is a personal fork of [the fastText project](https://github.com/facebookresearch/fastText), mainly intended to make it usable on Windows and in a NumPy 2.0 environment. It has not been thoroughly tested, so please use it with caution.

Here is the [original readme file](https://github.com/bfss/fastText/blob/main/README_ORIGIN.md)
